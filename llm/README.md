# LLM FAQ and Examples

This directory is for examples that connect AstroFlow with large language
models, agents, retrieval systems, or AI-supported scientific workflows.

Use this area for examples such as:

- Using an LLM to help assemble or inspect distributed workflows.
- Running document, metadata, or literature-processing pipelines.
- Combining retrieval-augmented generation with scientific datasets.
- Evaluating LLM-assisted analysis steps inside a reproducible workflow.
- Building assistant-style interfaces around AstroFlow jobs.

Each example should live in its own subdirectory and include a local `README.md`
with setup instructions, model or provider requirements, expected inputs, and
notes about cost, privacy, or reproducibility.

Avoid committing API keys, private prompts, generated cache files, or sensitive
data. When an example depends on a hosted model, document the provider and any
configuration required to run it.
